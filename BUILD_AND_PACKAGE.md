# Build and Package Instructions

All validation errors have been fixed! Follow these steps to build and package the plugin.

## Prerequisites

- Node.js 20+ installed
- ImageMagick installed: `brew install imagemagick`
- Stream Deck CLI tools installed

## Step-by-Step Instructions

### 1. Pull Latest Changes

```bash
cd /path/to/your/TwitchMod4Streamdeck
git pull origin claude/twitch-moderator-stream-deck-011CUKZzmo7zbu1vWT3G29Mk
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Build the Plugin

This creates the `bin/plugin.js` file:

```bash
npm run build
```

You should see: `created twitch-moderator-tools.sdPlugin/bin/plugin.js`

### 4. Convert Icons to PNG

**Install ImageMagick first (one-time):**
```bash
brew install imagemagick
```

**Then convert all icons:**
```bash
node scripts/convert-icons.js
```

This creates 42 PNG files (21 icons × 2 sizes).

**Verify conversion:**
```bash
ls twitch-moderator-tools.sdPlugin/imgs/*.png
ls twitch-moderator-tools.sdPlugin/imgs/actions/*.png
```

You should see:
- 4 PNG files in `imgs/`: `plugin.png`, `plugin@2x.png`, `category.png`, `category@2x.png`
- 38 PNG files in `imgs/actions/`: 19 icons, each with regular and @2x versions

### 5. Package the Plugin

```bash
streamdeck pack twitch-moderator-tools.sdPlugin
```

This creates: `com.twitch.moderator.tools.streamDeckPlugin`

### 6. Install the Plugin

Double-click the `.streamDeckPlugin` file, or:

```bash
streamdeck install com.twitch.moderator.tools.streamDeckPlugin
```

### 7. Verify Installation

1. Open Stream Deck software
2. Look for "twitch-moderator-tools" in the actions list
3. You should see all 36 actions available

## Troubleshooting

### Error: "CodePath file not found, 'bin/plugin.js'"

**Solution:**
```bash
npm run build
```

### Error: "Icon file not found"

**Solution:** Convert icons to PNG:
```bash
# Install ImageMagick
brew install imagemagick

# Convert icons
node scripts/convert-icons.js
```

### Error: "multiple files named 'imgs/...' found"

This is just a warning. The manifest now explicitly uses `.png` extensions, so PNG files will be used correctly.

### Build fails with TypeScript errors

These are warnings, not errors. The build succeeds despite them. You can ignore warnings about:
- Unused imports
- Type assertions

### Icon conversion fails

**Alternative methods:**
1. See `ICON_CONVERSION.md` for manual conversion
2. Use online converter: https://cloudconvert.com/svg-to-png
3. Use Figma/Sketch/Illustrator
